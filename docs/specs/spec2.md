### 📥 2.1. Модуль импорта и парсинга контента по URL 🌐

#### 🔄 Процесс загрузки:

1. **Ввод ссылки**: Пользователь вставляет URL страницы со стихотворением на Главном экране или в шапке билдера 🔗.
2. **Парсинг данных**:
* Извлечение **Названия стихотворения** 📌.
* Извлечение **Имени автора** 👤.
* Извлечение **Сырого текста стихотворения** (Raw Text) 📜.


3. **Инициализация проекта**:
* Создаётся папка `[Автор] - [Название]` 📁.
* Создаётся начальный `config.json` с зафиксированными исходными данными.

### 🧱 2.2. Visual Drag-and-Drop Builder (Конструктор структуры) 🎨

#### ✂️ Авторазбиение текста:

* При загрузке сырого текста система автоматически разбивает его на блоки.
* **Правило**: Каждая **пустая строка** разделяет текст на отдельный четверостишье/блок 🧱.

#### 🎛️ Функция классификации и типизации блоков (на английском языке):

Каждому блоку можно присвоить один из системных типы-тегов:

* **`Intro`** — Вступление 🎬
* **`Verse`** (Verse 1, Verse 2, ...) — Куплеты (нумеруются автоматически) 🎙️
* **`Chorus`** — Припев 🔁
* **`Bridge`** — Бридж (кульминационная перебивка) 🌉
* **`Outro`** — Завершение / Финал 🏁
* **`Vocal Break` / `Interlude` / `Instrumental**` — Вокальные и инструментальные перебивки 🎷

#### 🔄 Логика автоматического повтора Припева (`Chorus Logic`):

* Если пользователь назначает любой из блоков как **`Chorus`**, в интерфейсе активируется переключатель **«Auto-repeat Chorus»** 🔁.
* **Поведение**: Блок `Chorus` автоматически виртуально продублируется и вставится **после каждого куплета (`Verse`)** в скомпилированной итоговой лирике.

#### 🖐️ Интерактивные манипуляции с блоками:

* **Drag-and-Drop**: Перетаскивание блоков мышью для изменения порядка.
* **Инлайн-редактирование**: Быстрое изменение текста внутри любого блока.
* **Управление блоком**: Добавление нового блока, дублирование 📋, удаление 🗑️.

### 🎚️ 2.3. Структура компонента «Текстовый Блок» (UI Card) 🎛️

```text
┌───────────────────────────────────────────────────────────────┐
│ ☰  [ Chorus ] [⭐ Importance: 5]              [ 📋 ] [ 🗑️ ]   │
├───────────────────────────────────────────────────────────────┤
│  Лазурный день, прозрачный вечер,                             │
│  И звёзды яркие горят...                                      │
├───────────────────────────────────────────────────────────────┤
│ [ 🏷️ Type ]  [ 🎤 Voice Edit ]  [ ➕ Add Vocal Break ]        │
└───────────────────────────────────────────────────────────────┘

```

#### 🎨 Оформление:

* **Glassmorphic панель** с цветным индикатором слева (каждому типу тега соответствует свой тон: `Chorus` — фиолетовый, `Verse` — синий, `Bridge` — янтарный).
* **Hover-панель**: Кнопки действий появляются плавно при наведении курсора.
