---

### 📁 1.1. Файловая структура и менеджмент проектов 📂

Приложение работает по принципу **file-based хранилища** 💾. Для каждого поэтического клипа/workflow создаётся отдельная изолированная папка на диске.

```text
/app_data/
├── settings.json                       # Глобальные настройки приложения и API
└── /projects/
    └── [Author] - [Song Title]/        # Папка проекта (создаётся автоматически)
        ├── config.json                 # Главный JSON-файл состояния и логов
        └── /images/                    # Папка сгенерированных картинок
            ├── scene_1_v1.png
            ├── scene_1_v2.png
            └── scene_2_v1.png

```

#### 🛠️ Правило именования директорий:

* Имя папки формируется автоматически после парсинга стихотворения: `[Имя Автора] - [Название Стиха]` (например, `Пушкин - Зимнее утро`).
* Все недопустимые для файловой системы символы (`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`) автоматически санитизируются и заменяются на дефис `_`.

### 🏠 1.4. UI/UX Главного экрана (Landing / Hub) 🎨

#### 📐 Макет и компоновка:

* **Тема**: 🌑 Глубокая тёмная тема (`#0B0C10` / `#12141C`) с лёгким градиентным свечением на фоне.
* **Header**:
* Логотип приложения и статус подключения API.
* Кнопка **«+ Новый Workflow»** (вызывает модальное окно с вводом ссылки).
* Кнопка **«⚙️ Настройки»** (управление API-ключами и списком моделей).


* **Основная область (Сетка карточек / BENTO Grid)**:
* Все имеющиеся блоки-проекты отображаются в виде интерактивных карточек.
* **Сортировка**: Самые свежие (по дате изменения/создания) находятся **в самом начале** ⏱️.
* **Пустое состояние (Empty State)**: Если проектов ещё нет, показывается лаконичный полупрозрачный стеклянный блок с предложением вставить первую ссылку для начала работы ✨.



#### 🗂️ Анатомия карточки блока (Project Card):

```text
┌────────────────────────────────────────────────────────┐
│ ❄️ Александр Пушкин — Зимнее утро                      │
│ 📅 26 Июля 2026, 22:00                                 │
│                                                        │
│ 📊 Статус: [🎵 Suno Done] ➔ [🖼️ Scenes: 3/5 Ready]     │
│ 🏷️ Теги: Intro, Verse, Chorus                          │
│                                                        │
│ [ 📂 Открыть Workflow ]             [ 🗑️ Удалить ]     │
└────────────────────────────────────────────────────────┘

```

* **Эффекты**: Полупрозрачность (Glassmorphic) 🔥, микро-акцент при наведении (light border glow), плавный клик для входа в подробный workflow.
