## 🎵 ЧАСТЬ 3: Модуль AI-Скиллов & Интеграция с Suno AI 🎛️

---

### 🧠 3.1. Архитектура AI-Скиллов (Промптов) ⚙️

**AI-Скилл** — это специализированный шаблон инструкции для LLM, который преобразует структурированный стих в форматированные промпты для музыкальных нейросетей (Suno / Udio).

#### 📚 Типы скиллов для текстов и музыки:

* **`Suno Lyrics Adapter`** ✍️ — расставляет мета-теги вокала, пауз, инструментов (`[Verse]`, `[Chorus]`, `[Guitar Solo]`, `[Fade Out]`) и оптимизирует ритмику под пение.
* **`Suno Style Generator`** 🎸 — анализирует настроение, ритм и смысл стиха, формируя компактный промпт для поля *Style of Music* (например, `Melodic Rock, Synthwave 120bpm, Male Vocal, Nostalgic, Atmosphere`).

```
┌───────────────────────────────────────────────────────────────┐
│ 🎯 Выбранный скилл: Suno Structure & Style Pro (v1.2)         │
├───────────────────────────────────────────────────────────────┤
│ 📝 Шаблон промпта:                                            │
│ "Transform the following structured lyrics into a Suno-ready  │
│ format using strict brackets tags..."                         │
├───────────────────────────────────────────────────────────────┤
│ [ ✍️ Править вручную ]   [ 🎤 / 💬 Изменить через AI-пожелание ]│
└───────────────────────────────────────────────────────────────┘

```

---

### 💬 3.2. Гибридное изменение и доработка скиллов 🎛️

Пользователь имеет полный контроль над тем, как сработает AI-инструкция:

1. **Прямое редактирование (Manual Edit)** ✏️ — редактирование системного промпта вручную в текстовом редакторе.
2. **AI-корректировка через комментарий/голос (Refinement via AI)** 🎤💬:
* Пользователь вводит текстовое пожелание (например: *«Добавь больше джазовых акцентов и сделай упор на саксофонные соло»*) или **наговаривает голосом**.
* Запрос отправляется в LLM, которая переписывает базовый промпт скилла под новые требования.
* Обновленный скилл фиксируется для текущей итерации генерации.

### ⚡ 3.3. Пайплайн генерации и удобный UI для копирования 📋

#### 🔄 Цепочка выполнения (Execution Pipeline):

1. **Сборка контекста**: Берётся скомпилированный лирический блок из *Этапа 2* + Выбранный/скорректированный скилл + Глобально выбранная текстовая модель (Claude, GPT, DeepSeek).
2. **Запрос к LLM**: Модель генерирует 2 итоговых текстовых объекта:
* **`Suno Lyrics`** (размеченный текст песни).
* **`Suno Style`** (описание музыкального стиля).


3. **Отображение и Копирование (Copy Block UI)** 📋:
* Специальный выделенный **блок с гарантированным сохранением переносов строк и тегов** для идеальной вставки в Suno.
* Кнопка **«📋 Скопировать Лирику»** (в один клик).
* Кнопка **«📋 Скопировать Стиль»** (в один клик).



```text

│ 🎵 Результат генерации для Suno AI                             │
```

### 🔗 3.4. Завершение музыкального этапа и сохранение в JSON 💾

После того как пользователь сгенерировал трек в Suno, он вставляет итоговую ссылку на понравившуюся песню в специальное поле интерфейса 🎧.

#### 🧬 Запись данных в `config.json`:

```json
"suno_stage": {
  "selected_skill_id": "skill_suno_pro_v1",
  "skill_prompt_used": "Transform lyrics with tags...",
  "user_refinement_comments": [
    "Добавь джазовые акценты и соло на саксофоне"
  ],
  "model_used": "claude-3-5-sonnet",
  "ai_generated_style": "Dark Synthwave, Saxophone solo, Dramatic Male Vocal, 110 BPM",
  "ai_generated_lyrics": "[Intro - Saxophone Break]\nМороз и солнце...",
  "final_suno_track_url": "https://suno.com/song/example-id-12345"
}

```
